Materials and Implementation

The package contains starter code, fixed data manifests, four experiment configurations, interface tests, inherited project notes, and a report template. Download data with the supplied script. No dataset search or independent split is needed. The code runs on CPU; no GPU is needed.

Use Fashion-MNIST: ten classes of 28-by-28 grayscale clothing images. Course subsets contain 10,000 training, 2,000 validation, and 2,000 test examples. Training and validation are disjoint subsets of the official training partition. The test subset comes from the official test partition. Preserve the supplied manifests and actual sample IDs.

Implement three functions, following their docstrings and tests:

  1. SmallCNN.forward in src/models.py: two convolution-ReLU-max-pooling blocks (1 to 16 and 16 to 32 channels, kernel 3, padding 1, pooling 2). Flatten the output and apply a linear layer from 1,568 features to 10 logits.
  2. train_one_epoch in src/training.py: run one training pass with the supplied loader, optimizer, and criterion. Return sample-weighted mean loss, accuracy, and example count. The runner already sets cross-entropy loss, Adam at learning rate 0.001, batch size 128, and [0, 1] pixel scaling. Do not rescale the inputs.
  3. evaluate in src/training.py: evaluation mode without parameter updates, sample-weighted mean loss and accuracy, and actual evaluated sample IDs, including the final partial batch.

Inspect the surrounding workflow and repair problems you find. Run the supplied interface tests. Passing these tests does not establish that an experiment supports its conclusion.

Installation and Run Commands

Setup

Use Python 3.12 and install the supplied dependencies. The code runs on CPU; no GPU is needed. Run all commands from the extracted package directory.

python -m pip install -r requirements.txt
python prepare_data.py --data-dir ./data

Fashion-MNIST downloads automatically. Supplied manifests fix the course subsets: 10,000 training, 2,000 validation, and 2,000 test examples. No additional dataset or API key is needed.

Implement and Run

Complete SmallCNN.forward, train_one_epoch, and evaluate according to their docstrings. Then run:

python -m pytest tests/test_interfaces.py
python run_experiment.py --condition baseline --seed 17 --data-dir ./data --output-dir .
python run_experiment.py --condition baseline --seed 29 --data-dir ./data --output-dir .
python run_experiment.py --condition flip --seed 17 --data-dir ./data --output-dir .
python run_experiment.py --condition flip --seed 29 --data-dir ./data --output-dir .
python select_model.py --output-dir .
python evaluate_test.py --data-dir ./data --output-dir .

The files in configs/ record the four settings; the commands above already apply them. Selection compares condition means, breaks ties in favor of baseline, and uses the selected condition's seed-17 checkpoint. Inspect the pipeline and outputs before making claims.
