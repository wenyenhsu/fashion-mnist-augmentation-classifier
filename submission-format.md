# Submission Instructions

Submit two required files to the Gradescope assignment AI-Assisted Image Classification: report.pdf of at most two pages and code.zip. Grading focuses on the report. Write the report in English and follow report-template.md. Use any editor that exports a readable PDF; no prescribed font or exact layout is required.

Upload report.pdf to Report and code.zip to Code within the same assignment. Click Submit Answer for each upload. Open the uploaded PDF and confirm both files are present before leaving Gradescope. To revise before the deadline, replace the affected upload and submit that answer again. Check that both active files describe the same work. Course policies govern late submissions and approved extensions.

The code archive contains src/, configs/, manifests/, tests/, the four top-level Python scripts, and requirements.txt. README.md provides one packaging command. Exclude downloaded data, logs, model checkpoints, environments, and AI conversations. The staff-provided starter ZIP is a download; code.zip contains your own working source files.

If an experiment fails, submit both your current code and a report with N/A for missing measurements, the attempted step, and a short error description. Do not invent results to fill the template.

If either upload fails, use a private Piazza post to instructors before the deadline and describe the error.
